# Contribution Guidelines

Thanks for helping keep this list useful. Please make sure your pull request meets these rules:

- One pull request per entry, so each can be reviewed on its own.
- Use the format `- [Name](link) - Description.` The description starts with a capital letter, ends with a full stop, and says what the tool does in one sentence.
- Keep entries in alphabetical order within their section.
- Describe what the project does, not how good it is. No prices, rankings, "best" or "leading": they go out of date or can't be checked.
- Link to the project's own site or repository, not to a listing, review or affiliate page.
- The project must be available to use today. Waitlist-only products are accepted if the site is live; discontinued products are removed.
- Open-source entries should be maintained (not archived, with activity in the last year).
- If you work on the project you are adding, say so in the pull request. That's fine, and we do the same: this list is maintained by the TestOptim team, and TestOptim is listed once, in alphabetical order.

Found a dead link or a product that has shut down? Open an issue or a pull request removing it.
